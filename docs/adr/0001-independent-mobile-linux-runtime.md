# Independent Mobile Linux Runtime Delivery

The Linux environment is delivered as external, independently versioned Cordis bootstrap and runtime plugins, with Bionilux, a Debian minimal rootfs, and one shared app-level glibc Node.js package distributed as checksummed GitHub Release assets rather than Git/LFS content. Both plugins are opt-in and disabled by default; a release or APK update must never add them to an injection directory or enable them implicitly. This keeps DSH Mobile’s Bionic Node and Termux execution path unchanged, avoids duplicating Node into each rootfs, and lets system updates remain independent of app releases; automatic update checks are triggered only for an explicitly activated system when the installed DSH Mobile app version changes, while manual checks remain available. The Debian rootfs is an execution environment, not a security boundary.
